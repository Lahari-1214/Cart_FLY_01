CART_FLY STYLED TEMPLATES
=========================

1. Copy the "templates" folder into your Cart_FLY_01 project and replace the existing templates folder.
2. Copy the "static/css/style.css" file into:
   Cart_FLY_01/static/css/style.css
3. Your Flask routes, form actions, Jinja variables, image paths, Razorpay script and existing URLs have been preserved.
4. Do not replace app.py or config.py with anything from this package.
5. Restart Flask and hard-refresh the browser with Ctrl+Shift+R.

The styling uses a single shared CSS file so the project has a consistent design.
